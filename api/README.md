# API

Python scripts that use the JSONPlaceholder REST API to gather employee TODO data.

- `0-gather_data_from_an_API.py` - display an employee's TODO list progress
- `1-export_to_CSV.py` - export an employee's tasks to `USER_ID.csv`
- `2-export_to_JSON.py` - export an employee's tasks to `USER_ID.json`
- `3-dictionary_of_list_of_dictionaries.py` - export all employees' tasks to `todo_all_employees.json`
